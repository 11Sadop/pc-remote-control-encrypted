# PC Remote Control

حزمة تشغيل Windows للتحكم الآمن بالكمبيوتر من الجوال عبر موقع Firebase واتصال Cloudflare Tunnel مشفر.

## التحميل

[تحميل النسخة v21](https://github.com/11Sadop/pc-remote-control-encrypted/releases/download/v2026.08.10-smoother-h264-v21/PCRemoteControl_FHD60_v21.zip)

## التشغيل

1. حمّل ملف ZIP ثم اختر **استخراج الكل / Extract All**.
2. افتح المجلد المستخرج وشغّل `START_PC_REMOTE.bat`.
3. اترك نافذة الخادم مفتوحة حتى يجهز رابط Cloudflare.
4. من أداة الكمبيوتر اضغط **إضافة جهاز جديد** وامسح QR بالجوال.
5. وافق على طلب الربط من أداة الكمبيوتر. بعد الموافقة تحفظ الجلسة ولا تحتاج QR مع كل تحديث.

## تحسينات v21

- بث H.264 بدقة Full HD مع هدف 60 FPS عند سماح الجهاز والشبكة.
- جودة أعلى للـ 1080p و keyframes أقل لتخفيف النبضات والتقطيع.
- بفر تشغيل أهدأ على iPhone/Safari لتقليل الوقفات القصيرة.
- إصلاح خطأ تحميل في `app.js` كان يسبب سلوكًا غريبًا بعد تحديث الصفحة.
- الصوت يبقى على قناة مستقلة عن الفيديو لتقليل التأخير.
- الربط يتم عبر QR مؤقت وموافقة يدوية من أداة الكمبيوتر.

لا يحتوي هذا المستودع على الكود المصدري أو مفاتيح خاصة؛ تنشر حزمة التشغيل الجاهزة فقط.

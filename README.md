# PC Remote Control

نسخة عامة جاهزة للتشغيل من أداة التحكم بالكمبيوتر.

## التحميل

حمّل أحدث نسخة من صفحة Releases:

- PCRemoteControl_StableTunnel_v36.zip
- SHA256: $hash

## التشغيل

1. فك ضغط ملف ZIP كاملًا.
2. شغّل START_PC_REMOTE.bat واترك نافذة الخادم مفتوحة.
3. إذا علق التحديث شغّل START_PC_REMOTE_NO_UPDATE.bat.
4. افتح موقع التحكم من الجوال: https://pc-remote-control-sa.web.app
5. استخدم QR فقط لتسجيل جهاز جديد أو إعادة الربط.

## ملاحظات مهمة

- هذه النسخة تستخدم وضع بث ثابت للتونل 1280×720 / 45fps لتقليل التقطيع عبر Cloudflare.
- Full HD داخل الموقع خيار تجريبي وقد يقطع على Cloudflare.
- لا يوجد كود مصدر منشور داخل الحزمة.
- ملفات الخادم والواجهة داخل الحزمة معمّاة برمجيًا لتصعيب النسخ العشوائي.

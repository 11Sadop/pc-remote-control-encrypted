# PC Remote Control

حزمة تشغيل Windows للتحكم الآمن بالكمبيوتر من الجوال عبر موقع Firebase واتصال Cloudflare Tunnel مشفر.

## التحميل

[تحميل النسخة v19](https://github.com/11Sadop/pc-remote-control-encrypted/releases/download/v2026.08.06-input-jitter-v19/PCRemoteControl_FHD60_v19.zip)

## التشغيل

1. حمّل ملف ZIP ثم اختر **استخراج الكل / Extract All**.
2. افتح المجلد المستخرج وشغّل `START_PC_REMOTE.bat`.
3. اترك نافذة الخادم مفتوحة حتى يجهز رابط Cloudflare.
4. من أداة الكمبيوتر اضغط **إضافة جهاز جديد** وامسح QR بالجوال.
5. وافق على طلب الربط من أداة الكمبيوتر. تُحفظ الجلسة بعد الموافقة ولا يلزم QR عند كل تحديث.

## تحسينات v12

- بث H.264 بدقة Full HD وهدف 60 إطارًا عند سماح الجهاز والشبكة.
- قناة صوت مستقلة عن الفيديو لتقليل التقطيع والتأخير.
- قناة تحكم مباشرة للنقر والسحب والكتابة مع حماية من بقاء أزرار الإدخال عالقة.
- تحديث سريع للتطبيقات المفتوحة مع إغلاقها من الموقع.
- عرض الرام وحرارة GPU وحرارة CPU عندما يوفّر الجهاز حساسًا متاحًا.
- رجوع واضح داخل مدير الملفات وتنقل فوري بين الأقراص، والرفع إلى `Downloads`.
- أوامر طاقة فعلية ومراقبة انتهاء التحميل.
- جلسات محفوظة وتوكن CSRF وربط QR مؤقت وموافقة يدوية.

لا يحتوي هذا المستودع على الكود المصدري أو مفاتيح خاصة؛ تُنشر حزمة التشغيل الجاهزة فقط.

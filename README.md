# PC Remote Control

نسخة عامة جاهزة للتشغيل من أداة التحكم بالكمبيوتر عبر الجوال.

## التحميل

- اضغط تحميل من موقع التحكم: https://mihrabapp-32e80.web.app
- أو حمّل آخر إصدار من صفحة Releases في GitHub.

## طريقة التشغيل

1. حمّل ملف أداة الكمبيوتر من Releases.
2. شغّل الملف واترك نافذة الخادم مفتوحة.
3. من أداة الكمبيوتر اضغط **إضافة جهاز جديد**.
4. افتح موقع التحكم من الجوال وامسح QR.
5. اقبل طلب الربط من أداة الكمبيوتر.

## ملاحظات الأداء

- الوضع الافتراضي مرفوع إلى Full HD 1920x1080 مع هدف 60FPS.
- الأداء الفعلي يعتمد على قوة الكمبيوتر، سرعة الشبكة، وCloudflare Tunnel.
- إذا كان الاتصال ضعيفاً يمكن اختيار 1600 أو 1280 من الموقع بدون تغيير تلقائي للجودة.

## الأمان وحماية الفكرة

- لا يوجد كود مصدر منشور في هذا المستودع.
- البرنامج منشور كملف تشغيل Windows واحد ضمن Releases.
- النسخة مبنية بدون رموز تصحيح لتقليل سهولة قراءة التفاصيل الداخلية.
- أي برنامج يعمل على جهاز المستخدم يمكن تحليله بصعوبة متفاوتة؛ هذه الحماية تقلل وضوح الكود لكنها ليست حماية مستحيلة ضد الهندسة العكسية.

# PC Remote Control

نسخة عامة جاهزة للتشغيل من أداة التحكم بالكمبيوتر.

## التحميل

حمّل الحزمة الكاملة من آخر إصدار:

[تحميل PCRemoteControl_FHD60_v29.zip](https://github.com/11Sadop/pc-remote-control-encrypted/releases/download/v2026.08.10-smooth-openrgb-v29/PCRemoteControl_FHD60_v29.zip)

ثم:

1. فك الضغط بالكامل.
2. شغّل START_PC_REMOTE.bat.
3. افتح موقع التحكم: https://pc-remote-control-sa.web.app
4. اضغط من الأداة "توليد باركود" وامسحه من الموقع ثم وافق على الطلب.

## الجديد في v29

- تحسين بث FHD 60fps بإرجاع إعدادات البفر والبتريت الأعلى لتقليل التقطيع عبر Cloudflare.
- دمج OpenRGB داخل الحزمة في in-tools/OpenRGB للتحكم الاختياري بإضاءة RGB بدون تحميل منفصل.
- استمرار حماية الجلسات والكوكيز الآمنة والتعمية البرمجية لملفات JavaScript العامة.

## الأمان

لا يوجد كود مصدر منشور في هذا المستودع. الحزمة العامة تحتوي ملفات تشغيل فقط وملفات JavaScript مُعمّاة.

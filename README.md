# PC Remote Control

نسخة عامة جاهزة للتشغيل من أداة التحكم بالكمبيوتر عبر الجوال.

## التحميل

حمّل آخر حزمة ZIP من صفحة Releases، أو من زر التحميل في موقع التحكم:
https://mihrabapp-32e80.web.app

## طريقة التشغيل

1. فك الضغط عن الحزمة ZIP.
2. شغّل `START_PC_REMOTE.bat`.
3. اترك نافذة الخادم مفتوحة.
4. افتح موقع التحكم من الجوال.
5. من أداة الكمبيوتر اضغط **توليد باركود ربط جديد**.
6. امسح QR واقبل الطلب من الأداة.

## ملاحظة مهمة

لا تشغل ملف البث وحده؛ الحزمة الكاملة تشغل الخادم المحلي وCloudflare ثم أداة البث.

## الأمان وحماية الفكرة

- لا يوجد كود مصدر للتطبيق الأصلي منشور كتطبيق تطوير كامل.
- النسخة العامة تعمل كحزمة تشغيل جاهزة.
- أي برنامج عام يمكن تحليله بدرجات مختلفة؛ الحماية هنا تصعب النسخ المباشر لكنها ليست منعاً مطلقاً للهندسة العكسية.

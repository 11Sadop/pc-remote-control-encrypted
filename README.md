# PC Remote Control

نسخة عامة جاهزة للتشغيل من أداة التحكم بالكمبيوتر.

## التحميل

- حمل آخر نسخة من موقع التحكم: https://pc-remote-control-sa.web.app
- أو من GitHub Releases: https://github.com/11Sadop/pc-remote-control-encrypted/releases/latest

## التشغيل

1. حمل ملف ZIP.
2. اضغط زر الفأرة الأيمن واختر Extract All / استخراج الكل.
3. شغّل `START_PC_REMOTE.bat` واترك نافذة الخادم مفتوحة.
4. افتح موقع التحكم واضغط مسح الباركود عند تسجيل جهاز جديد.
5. وافق على طلب الربط من أداة الكمبيوتر.

## الأمان

- لا يوجد كود مصدر للأداة داخل هذه النسخة العامة.
- جلسة الجوال تحفظ بتوكن بعد الموافقة، ولا تحتاج باركود كل مرة إلا عند جهاز جديد أو إلغاء الربط.
- استخدم الحزمة الرسمية فقط وتحقق من ملف SHA256 عند الحاجة.
